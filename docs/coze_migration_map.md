## Stage 12 已确认事项

- Coze YAML 中的 `character_count` 在 stage12 语境下不是角色数量，而是每集/批次正文目标字数，统一由旧项目字段 `episodeWordCount` / `episode_word_count` 提供。
- 业务代码不新增特殊分支；映射仍集中在 `workflow_code_skeleton/config/coze_workflows.yaml` 的 `stage_12_write`、`stage_12_review`、`stage_12_rewrite`。
- 旧项目内部继续保存 `batchScriptText`、`batchScriptReview`、`scriptMemory`，并保留蛇形兼容字段 `batch_script_text`、`batch_script_review`、`script_memory`。
