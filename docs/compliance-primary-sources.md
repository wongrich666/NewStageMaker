# 国内影视、网络视听与微短剧合规检测：第一方依据研究

> 调研日期：2026-08-11  
> 适用目标：剧本平台的创作前提示、剧本扫描、修改建议、送审材料预检。  
> 证据范围：国家广播电视总局、国务院/国家行政法规库、国家电影局、全国人大法律法规数据库、各省级广电主管部门官方网站，以及平台官方协议、规则中心或帮助中心。  
> 重要边界：本模块只能做风险筛查和修改辅助，不能替代主管部门、播出平台或专业法律人员的正式审查，也不能承诺“过审”。

## 一、结论摘要

1. **检测对象不能只看台词。** 国家层面的公开标准覆盖片名、标题、剧情立场、人物塑造、语言、表演、字幕、画面、音乐、音效、宣传物料、版权和备案标识。脚本阶段应扫描“主题与价值取向、具体表达、人物结局、可视化呈现、权利链、报审路径”六层，而不是简单敏感词过滤。依据包括现行《电视剧内容管理规定》第五条、现行《互联网视听节目服务管理规定》第十六条，以及发布于国家广电总局网站的《网络短视频内容审核标准细则（2021）》。[电视剧内容管理规定（2010-05-14公布，2016-05-04修订，现行）](https://www.nrta.gov.cn/art/2015/5/21/art_3812_46.html)；[互联网视听节目服务管理规定（2007-12-29公布，2008-01-31施行，现行）](https://www.nrta.gov.cn/art/2007/12/29/art_1588_43750.html)；[网络短视频内容审核标准细则（2021）（2021-12-15发布，行业审核细则，现仍公开）](https://www.nrta.gov.cn/art/2021/12/15/art_113_58926.html)
2. **所有网络微短剧均存在许可或备案要求。** 现行公开管理口径要求微短剧先审后播，并取得《网络剧片发行许可证》或完成相应备案；自2024年6月1日起，未经审核且备案的微短剧不得上网传播。平台、小程序、投流方不得传播、引流未标注许可证号或备案号的微短剧。[广电办发〔2024〕35号（2024-02-05成文，国家广电总局于2025-02-05公开，现行管理口径）](https://www.nrta.gov.cn/art/2025/2/5/art_113_70148.html)
3. **“100万元”是明确存在的微短剧分类阈值，但不是“电影级”标准。** 现行口径把“总投资额度达到100万元及以上”列为重点微短剧条件之一；30万元（含）至100万元且非重点推荐为普通微短剧；不足30万元且非重点推荐为其他微短剧。特殊题材、平台主推/首页首屏推荐、自愿重点申报也可进入重点微短剧，和预算无关。[广电办发〔2024〕35号（2024-02-05成文，现行管理口径）](https://www.nrta.gov.cn/art/2025/2/5/art_113_70148.html)
4. **没有查到“100万元以上即电影级严格检测”的国家规定。** 电影适用电影备案、剧本/梗概和完成片审查制度，现行公开规则以作品类型、公开放映、特殊题材和内容风险为主要触发条件，没有按100万元划分电影审查等级。[电影剧本（梗概）备案、电影片管理规定（2006-05-22公布，2017-12-11修订，现行公开规章）](https://www.chinafilm.gov.cn/xxgk/zcfg/bmgz/202112/t20211214_441295.html)；[中华人民共和国电影产业促进法（2016-11-07公布，2017-03-01施行，现行）](https://www.npc.gov.cn/zgrdw/npc/xinwen/2016-11/07/content_2001584.htm)
5. **平台规则是国家底线之上的附加层。** B站公开社区公约对血腥暴力、低俗、未成年人、真实性、创作公平和低质观感等分类较细；抖音公开用户协议强调来源标注、第三方权益、原创/授权和AI内容标识，并把更细规范指向社区公约和规则中心；红果公开网页暂未检索到稳定、完整的创作者内容审核细则。因此平台层必须支持版本化、人工补录和“证据不足”状态，不能把行业传闻写成红果规则。[bilibili社区公约（当前在线规则页，页面未标注发布日期，2026-08-11核验可访问）](https://member.bilibili.com/studio/convention/content?index=2-2&navhide=1)；[抖音用户服务协议（当前在线版本，2026-08-11核验可访问）](https://www.douyin.com/agreements/?id=6773906068725565448)；[红果短剧官网（当前在线官网，未提供完整创作者审核规则入口，2026-08-11核验）](https://www.hongguoduanju.com/)
6. **2026年的《微短剧发展管理办法（征求意见稿）》尚未生效。** 可以作为规则变更预警源，但不得写进“现行硬规则”。该稿拟把微短剧改称一类、二类、三类，并提出AI生成制作微短剧的每集提示标识等要求；最终文本可能变化。[征求意见通知（2026-06-24发布，征求意见稿，非现行法）](https://www.nrta.gov.cn/art/2026/6/24/art_113_73514.html)

### 2.2 检测引擎必须区分的判断类型

- **存在即高风险**：例如分裂国家、泄露国家秘密、宣扬恐怖主义、淫秽内容、教唆犯罪、侵害未成年人等。系统可直接拦截并要求人工复核。
- **取决于作品立场和后果**：犯罪、反派、暴力、婚外情、迷信设定本身不宜用关键词一刀切。应同时判断叙事立场、行为后果、模仿性细节、镜头强度和人物结局。
- **取决于材料而非文本**：改编授权、真人授权、历史事实依据、特殊题材主管意见、许可证或备案号。缺材料只能报“待核验”，不能报“违规”或“通过”。
- **取决于成片**：血腥程度、裸露、字幕、音效、AI显式标识、片头备案号等无法仅凭文学剧本完成终检。报告必须显示“剧本预检覆盖范围”。

## 三、省级公开文件的可维护索引

### 3.1 不应做一次性“全国规则大拼盘”

省级网站大量内容是转发国家文件、办事指南、月度备案公示、扶持申报和阶段性专项治理。它们的法律层级、有效期和适用对象不同。正确做法是维护**来源索引 + 文件版本 + 规则提取物**，不把所有网页段落直接塞进模型提示词。

### 3.3 更新机制

1. 每个省只维护省级广电/文旅广电主管部门的**官方域名入口和栏目发现器**，不手写一份永不更新的“省级禁词表”。
2. 国家广电总局、国家电影局和国务院行政法规库每日或每周检查；省级“政策文件、通知公告、办事指南、备案公示、专项治理”栏目每周检查；平台规则页每日检查响应头/内容哈希。
3. 新文件先进入待审核区，由人工确认发布机关、层级、适用对象、时效和是否替代旧文件，再生成规则。
4. 转发件与国家原文去重：保留属地执行元数据，但规则正文指向国家规范；只有本地新增材料、流程、时限或窗口时才生成省级差异规则。
5. 规则命中报告必须显示“依据版本 + 核验日期 + 原文链接”，并允许审核人员一键标记误报。

## 五、普通检测与严格检测的合理分层

### 5.1 法规事实

对**网络微短剧**，现行分类分层审核口径为：

- 重点微短剧：特殊题材、总投资达到100万元及以上、长短视频平台招商主推或首页首屏推荐、自愿按重点申报等条件满足其一；
- 普通微短剧：总投资30万元（含）至100万元，且非重点推荐；
- 其他微短剧：总投资不足30万元，且非重点推荐。

依据：[广电办发〔2024〕35号（2024-02-05成文，现行管理口径）](https://www.nrta.gov.cn/art/2025/2/5/art_113_70148.html)。

这不是作品质量评分，也不是“100万元以上就是电影”。电影的备案、审查规则没有检索到同样的100万元分界；电影项目应按电影规则单独路由。[电影剧本（梗概）备案、电影片管理规定（现行公开规章）](https://www.chinafilm.gov.cn/xxgk/zcfg/bmgz/202112/t20211214_441295.html)

### 5.2 产品按钮建议

#### 普通检测

适合创作早期、低成本项目和内部快速筛查，但不等于低标准。

- 国家禁止性内容全量扫描；
- 未成年人、色情低俗、暴力犯罪、民族宗教、真实人物、版权、AI标识等基础风险；
- 所选平台公开规则差异；
- 片段级风险定位、理由、轻量修改建议；
- 准入问卷：类型、成本、题材、计划平台、推荐位、是否改编、是否AI成片；
- 输出“可继续创作 / 建议修改 / 必须人工复核 / 材料缺失”，不输出“保证过审”。

#### 严格检测

默认触发条件不应只有成本。满足以下任一条件均建议严格模式：

- 网络微短剧总投资达到100万元及以上；
- 特殊题材，或重大革命历史、重大现实、军事、公安、司法、民族、宗教、外交、国家安全等；
- 平台主推、首页首屏推荐、付费重点投流或自愿按重点微短剧申报；
- 电影、电视剧、面向未成年人的节目；
- 真人真事、历史名人、英模、真实案件、医疗法律金融等高事实风险；
- 改编、翻拍、跨境合作、使用大量第三方素材；
- AI生成或合成图片、声音、人物形象和视频。

严格模式增加：

- 全剧逐集、逐场、逐角色弧线检查，而非抽样；
- 片名、简介、宣传文案、付费卡点和投流素材联审；
- 特殊题材识别与主管部门/专家意见清单；
- 事实来源、版权授权、真人授权、音乐与素材权利链清单；
- 备案类型、主管层级、号码和送审版本一致性检查；
- AI显式/隐式标识交付检查；
- AI初审后必须人工复审并留下审查人、意见、修改版本和复审记录；
- 修改后重新检测，只对已复核版本生成报告。

### 5.3 按钮命名

建议前端使用：

- **普通检测**：快速合规预检
- **严格检测**：重点项目全量审查

在严格检测按钮旁写明：`100万元以上微短剧、特殊题材、平台重点推荐或高风险项目建议使用`。不要写“100万元以上电影级检测”，因为该表述会把微短剧管理阈值错误扩大到电影和所有剧本。

## 八、实施注意事项

1. 先做确定性路由：作品类型、成本、题材、受众、目标平台、是否重点推荐、是否改编/真人/AI；再调用模型理解剧情上下文。
2. 敏感词只用于召回候选片段，不能直接定性。最终风险说明必须引用完整场景、人物立场、后果和结局。
3. 修改建议应保留戏剧功能。例如暴力桥段不一定删除冲突，可降低模仿性细节、避免猎奇镜头、补足行为后果与价值立场。
4. 规则库与模型提示词分离。提示词只描述审查方法；具体规则、日期、条款和链接从版本化数据库检索注入。
5. 平台规则抓不到官方版本时显示“未核验”，不得用营销文章、自媒体课程或论坛帖补齐。
6. 每次正式报告固定证据快照；规则更新不得悄悄改写历史报告。
7. 高风险和特殊题材必须保留人工复核出口。AI可以提意见，不能代替行政许可、平台终审或法律意见。
