How It Works

使用说明

在这个剧本平台，你可以写剧本，看剧本，还可以评剧本，优化剧本

1

一句话创作剧本

点击【新建剧本】只需要填想要的剧本、角色数量和总集数，前置框架阶段会自动生成标题、大纲、人物、场景与分集计划。

2

多任务并行

同一账号可以同时开多个网页写剧本

3

后台继续跑

关闭当前页面不会中断任务；重新打开工作台后，可以继续查看进度、暂停恢复和下载成品。
