# 续写模式

仅当 `mode=续写` 时启用。已有剧本是不可随意改写的前史正典，本次只创作
`episode_start` 至 `episode_end`。

## 续写基线

总编剧先从已有剧本提取一份可供后续节点直接执行的续写基线：

- 已有最后一集的地点、时间、在场人物、最后动作和未完成事件；
- 主要人物当下目标、知情范围、伤势、关系、持有物和语言习惯；
- 已兑现与未兑现的承诺、秘密、伏笔、债务和正在累积的风险；
- 原作稳定的叙事视角、节奏、幽默或情绪强度，以及不能篡改的事实。

后续节点以上游续写基线和锁定产物为准，不重复总结整部已有剧本。

## 开始续写

- 第一集新内容必须承接已有最后一集的可见结果或未完成动作，再制造新的变化。
- 换地点前交代人物为什么去、准备做什么；新地点开场立即执行该行动。
- 不得让伤势、关系裂痕、已公开信息、丢失物品或人物决定无解释复原。
- 新人物、新规则和关键道具必须由当前剧情自然引入并承担后果，不能凭空解题。
- 可以短暂回扣必要信息，但禁止用大段前情提要替代正在发生的戏。

`strict` 策略严格保持既有人物、世界规则、语气和已发生事件；`light` 策略允许调整
后续节奏与支线重点，但仍不得推翻已经发生的事实。

## 输出边界

只输出 `episode_start` 至 `episode_end`。不得复制、改写或重新编号已有集数，
不得擅自多写目标集数之后的内容。
