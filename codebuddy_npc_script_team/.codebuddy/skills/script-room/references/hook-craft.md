# 钩子与爆点模块

## 验收合同

每集开头五秒内必须产生一个观众必须继续看的具体问题。钩子必须来自人物、关系、
危险、秘密或当前行动，不能只靠形容气氛，也不能把后文冲突机械搬到开头。

优先形式：

- 一句带后果的命令或禁止。
- 一句话同时包含表层意思和隐含威胁。
- 角色说出本不该知道的信息。
- 危险动作已经开始，人物必须立刻选择。
- 关系身份在一句话或一个动作中翻转。

## 逐集检查

1. 第一行是否已经进入动作、冲突或禁忌信息。
2. 钩子制造的问题是否在本集继续推进，而非开场后消失。
3. 开场是否承接上一集未完成动作或结果。
4. 中段是否至少发生一次局势变化。
5. 结尾是否留下未完成动作、危险决定、关系翻转或关键信息。

## 修订规则

- 钩子不足时直接重写开场，并同步修正本集后文的因果。
- 优先压缩解释，让人物在压力下行动或说话。
- 人物、证据、技术和道具按剧情需要使用；不得新增无来源、无铺垫、无代价的万能解题元素。
- 不用“殊不知”“命运的齿轮”“一场阴谋正在逼近”等旁白代替事件。
- 尾钩必须改变下一集的行动条件，不只是宣布“事情还没结束”。
