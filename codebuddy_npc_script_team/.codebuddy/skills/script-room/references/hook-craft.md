# 钩子与爆点生产模块

本模块只负责让开场立刻进入戏。钩子必须来自既有主线、人物关系、规则、秘密或行动，
不靠无关事故、突然能力和临时身世骗点击。

## 第一有效拍

场景头后的第一句台词或第一个动作，必须让主角立刻面对一个不可回避的问题，并让观众
产生具体追问。优先从四类入口中选择最适合本剧的一种：

- 高压命令：权力关系立即落到主角身上。
- 异常事实：熟悉秩序出现可验证的错误。
- 关系破位：称呼、承诺、身份或位置突然改变。
- 不可逆选择：人物必须马上决定，并承担明确后果。

一句已经足够时立即收住。禁止在此前扫描环境、介绍人物、解释设定、起床赶路或普通寒暄。
大喊、枪声、爆炸、流血和特效如果没有私人代价与后续行动，不算有效钩子。

## 四拍落地

优先使用最短结构：

`爆点短句/动作 → 即时后果 → 最短因果锚 → 主角反应或选择`

“及时雨”式有效点不在于固定写“跪下”，而在于一句命令同时暴露权力差，下一拍立刻产生
后果，再用一句关系信息说明伤害为何落到此人身上，最后让主角的反应显露反差。

因果锚只回答观众理解眼前冲突所需的一层：为什么此刻发生、为什么落到这个人物身上。
它必须来自有信息来源且正在参与事件的人物反应、指控、通知、规则反馈或可见结果。
钩子本身已经包含原因时不得重复解释，也不得新增只负责讲背景的路人。

## 题材适配

- 情感与家庭优先关系旧债、称呼和承诺变化。
- 喜剧优先身份错位、规则碰撞和不可撤回的现实后果。
- 悬疑惊悚优先“不该出现的信息”与已经开始的危险。
- 成长逆袭优先具体损失、压迫和主角必须承担的选择。
- 奇幻科幻优先可验证的规则异常及其对人物目标的即时影响。

这些是入口，不是模板。不得机械套用打脸、掉马、车祸、监控、证据或暴力。

## 集间钩子

第N集尾钩必须改变第N+1集的行动条件。下一集先处理这个结果，再升级新问题。
小问题原则上一集内回应；重要问题三集内至少部分兑现。只提问、不提供新证据或阶段答案，
不算有效追剧链。

## 修改边界

钩子不足时可以重写开头1至3个有效拍，并删除重复铺垫，但不得新增重大人物、秘密、
能力、身份或世界规则，不得改变主角当集目标、本集结果和下一集承接动作。
