# 钩子与爆点生产模块

本模块用于创作阶段直接写出有效钩子，不输出评分或审查报告。钩子服从题材、人物、
受众和创作合同，不把所有故事都写成吼叫、打脸、身份曝光或暴力危险。

## 黄金三秒硬门槛

第一帧、第一句台词或第一个有效动作必须立刻抛出`冲突、悬念、反差、危险后果`
中的至少两项，让观众马上追问“为什么、接下来怎么办、主角会失去什么”。第一有效拍
之前禁止环境扫描、起床赶路、人物介绍、背景解释、普通寒暄和无后果忙碌。

强钩子优先采用短句和可拍动作，可以只有一句话。它必须来自既有人物、关系债、秘密、
规则或当前行动，并在紧接着的戏里改变人物选择。钩子不足时允许依据上下文新增异常
结果、高压命令、关系翻转或即将支付的代价，同时补齐后续因果，不能用无关事故骗点击。

第一集执行黄金三秒最高门槛；其余各集仍须在前五秒承接上集结果并重新点燃问题。

## 黄金五秒合同

每集场景头后的第一句对白或第一个动作，必须让观众立刻产生一个具体追问。有效钩子
至少同时具备以下四项中的三项：

1. `当下性`：事情正在发生，人物不能稍后再处理。
2. `异常或压力`：正常秩序被一句话、动作、关系、结果、规则或信息打破。
3. `私人含义`：它刺中人物正在保护的关系、尊严、身份、安全、资源或承诺。
4. `行动后果`：人物必须反应、隐瞒、选择、反击或付出代价。

第一集优先比较三类入口后再落笔：关系旧债、身份或信息差、即时危险或两难选择。
选择最符合本剧情、最能改变人物行动的一种，不把三个入口机械叠加。

## 题材适配

- 爱情与家庭：称呼、旧话、承诺、亲情债或关系位置突然改变。
- 喜剧：身份错位、规则碰撞、误操作造成不可撤回的现实后果。
- 悬疑与惊悚：熟悉信息出现在不该出现的位置，危险已经开始而非只报预告。
- 成长与逆袭：压迫落到具体损失，主角必须选择忍、反击或承担更大代价。
- 职场与现实：公开站队、利益冲突、责任转移或制度规则当场压到个人。
- 奇幻与科幻：世界规则发生可验证的异常，并立即影响人物目标。

以上只是判断方向，不是固定模板。题材已有更自然的矛盾入口时，以人物和因果为准。

## 伪钩子

以下内容不能单独算钩子：

- 月光、天气、房间、喘息、脚步、瞳孔变化和连续道具特写。
- “一切才刚刚开始”“更大的危险正在靠近”等作者预告。
- 只有大喊、打斗、车祸或爆炸，却没有具体对象和私人代价。
- 与正文无关的梦、假危险、预告片式闪回或无后果狠话。
- 把后文高潮原封不动剪到开头，破坏时间、信息揭露和后续兑现。
- 在原有慢铺垫前贴一句狠话，随后人物若无其事地回到旧正文。

## 写法

优先采用最短有效拍点：

`高压台词或异常动作 -> 人物破绽/反击 -> 必要的私人含义 -> 当集行动`

第一句已经足够强时立即进入戏，不追加背景解释。允许一句有双层含义的台词、一个
打破关系平衡的称呼、一个不可逆决定或一个不该出现的信息成为完整钩子。

钩子不足时允许从既有人物、欲望、秘密、旧债、场景、规则和后续结果中创造一句新台词、
一次主动行为、一个即时阻碍或一次小暴露，但不得新增重大身世、能力、角色和世界规则。

新增钩子后必须形成：

`新爆点 -> 即时反应或选择 -> 最短因果桥 -> 当集目标 -> 后续回声`

必要时同步改写开头后续一至三个拍点，删除与新钩子重复或矛盾的旧铺垫。

## 心理与回忆

短心理可以采用“假设 -> 观察验证 -> 暂时结论 -> 新证据动摇”的循环，但必须改变
人物下一步行动。完整回忆场必须有目标、阻力、选择、代价和未偿旧债；一至三句记忆刺点
只需为当下台词增加第二层含义，并改变人物判断，不强行展开完整前史。

## 集间接力与尾钩

第 N 集尾钩必须改变第 N+1 集的行动条件，可以是未完成动作、迫近后果、关系换位、
新信息或有代价的选择。下一集先处理这个动作或后果，再展开新事件。

重要悬念应在合理篇幅内部分兑现：小答案解决眼前问题，大答案继续推动关系、秘密或任务。
只提出问题而长期不给新证据，不算有效钩子接力。

## 爽点密度与前五集立剧

- 前五集必须完成主角标签、核心欲望、核心矛盾、主要阻力、情绪承诺和追剧主问题；
  后续只负责升级、变奏和兑现，不得再补基础人设。
- 每集至少一个情绪高点，每30至60秒出现一次可见的局势换手或情绪释放，例如打脸、
  逆袭、揭秘、误判被推翻、关系倒置或代价落地，但不机械重复同一种爽点。
- 爽点至少改变资源、关系、认知、身份、行动条件或风险等级中的一项。
- 每集结尾必须留下会直接改变下一集开场行动的悬念，集间零冷却。
- 小钩子原则上一集内回应，重要钩子三集内至少部分兑现；兑现后立即产生更深问题。
- 用户明确免费转付费节点时采用“卡点不卡心”：本集已有阶段进展，再把最大悬念和
  未满足爽感放到结尾，不故意截断一句话或藏起理应给出的答案。
