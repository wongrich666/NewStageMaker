# 创作技能智能路由

总编剧在创作前根据用户材料生成创作合同，并决定增强 Skill 是否启用。用户不需要懂
专业术语；用户明确方向时优先服从，信息不足时根据题材、主角目标、情绪承诺和结局推断。

基础模块`hook-craft`、`character-voice`、`continuity`和`story-state-schema`
按照节点职责常驻。它们是跨题材质量底线，不属于剧情套路。

当前可选增强模块：

- `adversity_payoff`：主角逆风、情绪债、阶段性回击和反转兑现。

## 启用判断

`adversity_payoff`使用三级路由：

- `core`：用户明确要求逆袭、复仇、打脸、受压翻盘、隐藏身份兑现，或者作品核心情绪
  明显依赖“压迫期待 -> 主角反击 -> 权力关系翻转”。
- `support`：题材需要阻力、成长、悬疑、生存或关系压力，但最终吸引力不以公开翻盘为核心。
- `off`：纯治愈、日常观察、单元轻喜、氛围实验等作品中，逆风反转会破坏用户承诺。

不能仅凭“狼人、都市、爱情、古装”等题材名决定路由。同一题材可以使用完全不同的
叙事引擎。也不能把“冲突”自动等同于“全世界无理迫害主角”。

## 创作合同输出

创作任务书必须包含一行合法、单行JSON，供后续节点读取：

`SKILL_ROUTING_JSON: {"adversity_payoff":"core|support|off","reason":"简短判断依据"}`

只能选择三种等级之一。随后用自然语言写明：

- 核心观众情绪。
- 主角的叙事锚点。
- 主要压力来自利益、关系、规则、环境还是主角自身。
- 作品希望如何兑现承诺。

后续节点只读取被路由为`core`或`support`的增强模块。`core`必须落实到架构、分集、
正文和终审；`support`只在自然适配时使用，不得压过原题材；`off`不得偷偷套用该套路。
