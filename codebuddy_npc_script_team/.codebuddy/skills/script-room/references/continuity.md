# 集间、主角与事实连续生产模块

本模块用于在分集和正文阶段防止瞬移、任务丢失、主角失去行动权以及人物状态跳变。
可以省略没有戏剧价值的赶路，但不能省略行动原因和因果结果。

## 主角锚点

先依据创作合同确定核心叙事锚点，不得只凭男频、女频或人物性别机械判断：

- 单主角：主角持续承担核心目标、关键选择和主要后果。
- 双主角：每段明确当前视角锚点，交接必须由共同事件或关系选择触发。
- 群像：每集仍要有主要行动承担者，不能用“群像”掩盖因果断线。

主角不必获胜，但必须在选择、行动、承受后果或改变策略。只听汇报、等反派安排、
被配角拖着走或事后赶到，不算推动剧情。

## 相邻集交接链

逐对设计并检查每一组`第 N 集 -> 第 N+1 集`：

`上集最后事件/未完成动作 -> 人物决定 -> 去向或下一任务 -> 下集第一个有效动作 -> 承接结果`

- 上集提出事件A，下集不能无解释地直接处理事件B。
- 换地点时，上集说明为什么去、去做什么；下集从执行或准备执行开始。
- 时间跳跃必须标明时间，并交代跳跃期间决定性行动的结果。
- 切到支线必须由上一事件触发，并尽快说明它与当前主线的关系。
- 允许一句决定、一个来电、一个目光确认或一个动作完成最短因果桥，不增加流水账路程。

## 每集行动卡

每集按以下链条组织：

`承接点 -> 主角当集目标 -> 对抗目标 -> 主动行动 -> 阻力 -> 选择 -> 代价 -> 状态变化 -> 尾钩`

默认每集一至两个核心场景。剧情确实需要增加时，必须让新增场景承担新的选择、关系碰撞、
信息变化或不可替代的视觉行动，不能只换地点继续同一段解释。

每一场结束时至少改变一项：目标进度、权力关系、信息差、资源、信任、危险或下一行动。

## 人物与事实状态

逐集保持以下事实连续：

- 人物位置、时间、伤势、服装和持有物。
- 谁知道什么、何时知道、是否有合理信息来源。
- 人物关系、称呼、承诺、误解和刚刚发生的情绪余波。
- 新人物为什么在此刻出现，谁召唤、寻找、派遣或触发了他。
- 新道具、能力、证据和技术从哪里来，使用是否需要条件或代价。
- 上集未完成的动作、任务、问题和承诺是否被处理或明确延后。

## 主角行动权门禁

出现以下情况必须在分集阶段修复：

- 主角连续两集没有影响结果的主动选择。
- 关键证据、答案或解决方案全部由配角送到主角手中。
- 为制造反转让主角突然失忆、降智、忽视眼前目标或违背既定动机。
- 主角突然知道信息、改变立场、拥有道具或到达地点，前文没有来源。
- 配角和反派完成主要行动，主角只围观、惊讶或复述结果。

主角暂时缺席时，其他人物的行动仍应回应主角此前造成的事件，并尽快完成视角交接。

## 修复顺序

先修最早出现的因果断裂，再恢复主角行动权，然后修正人物状态、关系余波和细节。
修复应使用最短有效桥，不为解释连续性新增无戏剧价值的场景。
