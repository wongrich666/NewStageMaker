# 主线与集间连续生产模块

本模块防止主线丢失、集间瞬移、人物状态跳变和配角替主角解决问题。

## 主线锚

所有节点服从创作任务书中的 `MAINLINE_LOCK_JSON`：主角为了核心目标持续采取行动，
核心阻力作出反应，主角承担代价并调整策略，最终走向锁定结局。题材 Skill 只能改变表达，
不能替换这条主线。

每集必须明确推进以下至少一项：目标进度、阻力升级、关键信息、核心关系或实际代价。
只增加气氛、误会、受虐、谈话和新人物，不算推进主线。

## 相邻集接力

逐对执行：

`上集结尾状态 → 人物决定/行动目的 → 下集第一有效动作 → 承接结果`

- 第N集“结尾状态”和第N+1集“承接事实”必须是同一事实。
- 换地点时，上集给出去向、目的或触发原因；下集从准备执行、正在执行或承受结果开始。
- 可以省略无戏剧价值的赶路，不能省略决定、关键过程和结果。
- 时间跳跃必须说明跳跃期间决定性行动的结果，不能用“第二天”掩盖断层。
- 切支线必须由上一事件触发，并在两集内回撞主线。

## 主角行动权

单主角持续承担目标、关键选择和主要后果；双主角明确当前行动锚；群像每集也必须有主要
行动承担者。主角可以失败，但不能只听汇报、等待安排、事后赶到或让配角送来全部答案。

出现以下情况必须修复：

- 主角连续两集没有影响结果的主动选择。
- 新人物、能力、道具、证据或知识没有来源。
- 人物为了推进剧情突然降智、失忆或违背既定动机。
- 上集留下的任务、关系余波和未完成动作无解释消失。

## 事实状态

逐集保持人物位置、时间、伤势、服装、持有物、知情范围、称呼、关系、承诺、误解、
未完成动作和开放悬念。新元素使用前必须由寻找、召唤、派遣、交付、发现或规则触发自然引入。

修复时先修最早的因果断裂，再恢复主角行动权，最后校正状态细节。使用最短有效桥，
不为解释连续性新增没有戏剧价值的场景。
