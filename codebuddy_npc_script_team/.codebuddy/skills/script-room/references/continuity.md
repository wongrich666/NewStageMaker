# 集间与事实连续模块

## 集间交接链

第 N 集结尾与第 N+1 集开头必须形成：

`未完成动作或结果 -> 人物决定 -> 去向或受阻 -> 下一集开场动作`

允许省略无戏剧价值的路程，但不能省略为什么去、去做什么、上一集问题如何带入。
切到支线时，必须由上一集事件触发，并尽快说明它与主角当前任务的关系。

## 每集场景卡

正文前锁定：

`承接点 -> 场景目标 -> 对抗目标 -> 转折 -> 选择 -> 代价 -> 状态变化 -> 尾钩`

默认每集一至两个核心场景。超过两个时，`story_state.json` 必须记录
`scene_exception_reason`，说明为什么无法在两个场景内完成。

## 结构化事实

每集结束后记录：

- 人物位置、伤势、服装和持有道具。
- 每个人已经知道、误以为和仍不知道的信息。
- 戒备、合作、背叛、和解、决裂等关系变化及触发事件。
- 新人物、新道具首次出现的集数和来源。
- 已埋伏笔、已兑现伏笔和仍未完成动作。

## 禁止断裂

- 上集仍在对峙、追赶、救人或等待答案，下集突然处理无关事件。
- 地点、伤势、服装、道具、同伴或知情范围无解释改变。
- 新人物或关键道具第一次出现就承担解题功能。
- 用“后来”“第二天”跳过上集尾钩承诺的决定性过程。
- 配角替主角完成关键选择，导致主角连续多集失去行动权。

修复最早出现的断裂，再修主角行动权，最后修关系与细节。
