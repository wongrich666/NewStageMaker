# 主角逆风、情绪债与反转兑现生产模块

本模块只在创作合同将`adversity_payoff`路由为`core`或`support`时读取。它不要求所有
作品都让“全世界无理由与主角为敌”，而是让适合逆风叙事的作品形成合理压力、主动反击
和有伏笔的情绪兑现。

## 核心原则

压迫不是目的。每一次受阻至少完成以下两项：

1. 夺走或威胁主角的身份、关系、尊严、资源、安全或承诺。
2. 迫使主角作出更困难且能暴露性格的主动选择。
3. 加深一笔需要后续偿还的关系债或情绪债。
4. 暴露主角弱点、自我谎言或错误策略。
5. 埋下一项未来可以合理翻盘的能力、信息、关系、规则或选择资产。

对手和环境压力必须具有合理来源：

- 利益冲突：主角成功会损害谁的资源、地位或计划。
- 关系冲突：爱、亏欠、嫉妒、误解、控制或价值观分歧。
- 规则冲突：制度、族群、阶层、礼法、任务或生存限制。
- 外部威胁：有能力、有目标且会调整策略的对手或环境。
- 内部阻力：恐惧、羞耻、自我否认、错误信念或能力代价。

配角不能统一降智或无缘无故作恶。可以让多条合理压力在同一场戏中同时挤压主角。

## 压力与回报曲线

不要连续多集只让主角挨打。根据篇幅采用阶段性回报：

`压力建立 -> 主角尝试 -> 局部受挫/付代价 -> 小回击或新认知 -> 更大压力 -> 主动布局 -> 核心反转 -> 兑现`

“压三回一”只是可选节奏参考，不是固定公式。短篇可以更快回击，长篇可以分层兑现。
每次小胜应让观众获得回报，但不能提前解决核心矛盾；每次失败应改变策略或积累资产，
不能重复同一种羞辱。

主角可以暂时输，但不能连续两集没有主动选择。反击不一定是打脸，也可以是拒绝、
保护、揭穿、忍耐布局、改变关系、承担代价或选择不成为对手那样的人。

## 三张账

架构和分集阶段必须维护：

### 压力线

记录压力来源、对方合理动机、使用的力量、主角当前损失以及下一次升级方式。

### 情绪债

记录具体事件、谁欠谁、观众期待看到什么回应、计划在哪一阶段部分或集中偿还。
重要羞辱、背叛、误解和牺牲不能发生后就被遗忘。

### 翻盘资产

记录能力、信息、关系、规则、身份、承诺和主动选择的埋设与兑现。最终核心反转至少
由两项前期资产共同支撑，不能突然出现新人物、新能力、新证据或万能道具解决问题。

## 反转与兑现

极致反转的价值不是“原来如此”一句话，而是同时完成：

- 改写观众和人物对前文的理解。
- 让主角此前承受的压力获得意义或反击条件。
- 公开、具体地改变权力关系、关系位置或行动结果。
- 迫使对手和重要关系人物作出无法回避的反应。
- 让主角付出符合主题的代价，或证明其主动选择。

可使用身份、能力、证据、联盟、规则、情感或道德选择完成反转，但必须从本故事已有
资产中选择，不把所有题材统一写成身份掉马和众人跪服。

## 分集执行字段

启用本模块后，每集规划应明确：

- 本集哪条压力线落到主角身上。
- 主角主动做了什么，而不是只承受什么。
- 本集失去或冒险失去什么。
- 是否积累情绪债或翻盘资产。
- 本集给予何种局部回报。
- 总局势是改善、恶化还是表面改善实际恶化。

## 终审门禁

- 删除只有受虐、没有选择和后续价值的重复压迫。
- 补回被正文写丢的情绪债、翻盘资产和阶段性回报。
- 核心反转若依赖未铺垫元素，优先用既有资产重构，不临时补万能答案。
- 检查压迫与兑现的强度是否匹配；重大情绪债不能用一句道歉轻轻结束。
- 检查最终胜利是否由主角的行动和选择促成，而不是对手突然变笨或外援代劳。
