# 人物共鸣与声音模块

## 人物声音配方

每个主要人物必须在 `story_state.json` 中固定：

- `sentence_length`：常用句长和节奏。
- `evasion_style`：回避问题、撒谎或转移话题的方式。
- `pressure_pattern`：压力下语速、措辞和动作如何变化。
- `forbidden_phrases`：该人物不会说的措辞。
- `samples`：三句能区分人物的声音样本。
- `unspoken_truth`：最不愿直接承认的事实。

## 人情味

人物可以误判、嘴硬、犹豫、自我推翻、迁怒和言不由衷，但行为必须来自既有欲望、
恐惧、羞耻、关系债或信息边界。不要用“善良、复杂、愤怒、痛苦”等结论代替动作。

对话优先表达：

1. 人物此刻想让对方做什么。
2. 人物不能直说什么。
3. 人物如何保护自尊或隐藏恐惧。
4. 对方哪句话改变了权力关系。

## 去 AI 味门禁

- 不让不同人物使用相同句长、完整语法和总结口吻。
- 不让人物复述观众刚看到的剧情。
- 不让人物完整解释自己的心理、身份和关系。
- 删除无动作后果的形容词和连续排比。
- 避免“你知道吗”“其实我一直”“这一切都是因为”等解释性起手式。
- 重要情绪优先通过停顿、改口、错误动作、回避目光或反常选择呈现。

## 标点与口语节奏

- 普通陈述、动作接续和一般转折优先使用逗号、句号、问号或感叹号。
- 迟疑、吞回半句话、声音渐弱和未尽之意使用省略号。
- 破折号只用于三类情况：台词被突然打断、人物猛然改口、语义被强制跳转。
- 不用破折号连接普通动作与结果，不连续堆叠破折号，不给每句强情绪台词统一加破折号。
- “实习生是吧——这个月工资扣一半！”应改为“实习生是吧？这个月工资扣一半！”
- “说啊。说啊。你倒是说啊——”可按情绪收紧为“说啊。你倒是说啊！”
- “我没有拿——”后一句被另一个人物强行截断时，破折号可以保留。

## 正文署名格式

- 对白独立成行，固定写成 `人物名：台词`，不能省略说话者。
- 关键对白需要呈现表演时，写成 `人物名：（语气/情绪，眉眼神情）台词`。
- 例如：`打工鱼：（无奈，眉心微蹙）呃，我……`
- 中文全角括号紧跟冒号；括号内优先同时包含声音状态与眉眼反应，保持简短、可拍。
- 不在括号内解释心理、塞入长动作或写“生气地说道”；不为每句对白加括号。
- 每集至少让一处关键情绪转折对白带有准确表演提示，不连续复用同一神情。
- 心理活动固定写成 `人物名OS：心理活动`，不能只写“OS”“内心”或无主语旁白。
- 动作仍写成可视动作，不要为了套格式把动作误写成对白。
