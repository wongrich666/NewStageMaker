# 人物共鸣、声音与自然对白生产模块

本模块用于从人物设计到正文保持人物有欲望、有矛盾、有私人语言。目标不是让所有人物
讨喜或温柔，而是让观众能够理解、担心、心疼、好奇或愿意追随。

## 人物心理发动机

每个主要人物必须明确：

- `want`：当下公开想得到什么。
- `need`：真正需要面对但尚未承认什么。
- `fear_of_loss`：此刻最怕失去的关系、尊严、身份、安全、资源或承诺。
- `self_lie`：为了维持自我形象正在相信什么。
- `unspoken_truth`：在特定关系中最不肯说出口的真话。
- `pressure_pattern`：压力升高时如何说话、回避、迁怒、讨好、攻击或沉默。

人物行为采用：

`外部刺激 -> 人物化判断/联想 -> 自我否认或矛盾冲动 -> 选择 -> 可见后果`

心理活动可以保留，但必须改变观察、判断或下一动作；不能只是“我很难过”“他很震惊”
等情绪结论，也不能由作者替人物总结人生。

## 共鸣来源

有效共鸣来自：

`普遍心理 + 私人细节 + 具体代价 + 主动选择`

私人细节必须属于该人物的职业、年龄、经历和关系历史，并承担触发记忆、暴露关系、
增加压力或推动选择中的至少一项。不要用新增疾病、死亡、童年创伤和悲惨身世强行索取同情。

人物做出情绪选择后保留一个短余波，例如称呼改变、消息没有发出、熟悉动作被收回、
没有像从前一样追出去。哭、吼、和解或决裂后不能立即无缝进入下一项任务。

## 标签化人设与反差发动机

每个主要人物先提炼一个观众一眼能记住、又能制造行动压力的标签，优先采用：

`外在身份/处境 + 长期欲望或伤口 + 反差能力/秘密`

标签必须在人物首次有效登场时通过选择、动作、他人反应或一句有后果的台词被看见，
不能只停留在人物小传。公开身份与真实能力、口头态度与实际选择、渴望与恐惧、强项与
软肋至少形成一组持续拉扯。不同题材自行选择反差，不机械套用隐藏首富、顶级黑客、
失忆或双重身份。

前五集内，主角标签、核心伤口、自我谎言和主要关系压力必须各通过至少一个可拍事件
落地；后续只升级和推翻认知，不重新补发基础人设。

## 人物声音配方

为主要人物固定：

- 句子长短与节奏。
- 常用措辞和绝不会说的措辞。
- 回避问题的方式。
- 压力下语言和动作如何变化。
- 面对不同关系对象时的称呼、礼貌和攻击方式。
- 三句能够互相区分的声音样本。

声音差异来自身份、欲望和关系，不靠口头禅堆砌。财务人员、厨师、少年、老人、医生
对同一事件关注的细节、比喻来源和判断速度应当不同。

## 对白与潜台词

每句重要对白都要知道：说给谁听、想让对方做什么、真正不愿承认什么。

每集至少安排一次人物情绪状态变化，写清触发点、外显反应和新选择。情绪曲线不能
只有“更生气”；期待转羞耻、强撑转求助、得意转恐惧、误判转心软、压抑转反击都可
成立。情绪高点必须推动关系或行动，不用大喊大哭冒充强情绪。

- 允许打断、避答、说反话、半句话、换话题和沉默。
- 不把动机、关系历史和世界设定完整解释给本来就知道的人。
- 不让所有人物都说完整金句、总结主题或使用同一种礼貌书面语。
- 配角不能只递消息、夸主角、制造误会或替主角作决定。
- 重要关系对白应携带旧称呼、旧承诺、权力变化或未偿还的情绪债。

## 去AI味

主动删除或改写：

- 批量重复“瞳孔骤缩、呼吸一滞、攥紧拳头、嘴角勾起、眼底闪过、空气凝固”。
- “不容置疑、掷地有声、仿佛、宛如”等没有人物经验支撑的套式修辞。
- 连续罗列光线、气味、衣服、桌椅、手机和天气后再总结气氛。
- 用多个形容词代替一个具体动作、选择或关系反应。
- 人人都能互换的正确废话、信息播报和完整动机说明。

每个情绪拍点通常保留一至两个有效细节。细节越多不等于越真实。

## 标点与口语节奏

- 普通陈述和转折使用逗号、句号、问号或感叹号。
- 迟疑、吞回半句话或声音渐弱使用省略号。
- 破折号只用于突然打断、猛然改口或强制语义跳转。
- 不连续堆叠破折号，不用破折号连接普通动作和结果。

## 正文署名格式

- 对白独立成行：`人物名：台词`。
- 关键情绪转折可写：`人物名：（语气/情绪，眉眼神情）台词`。
- 表演提示简短、可见、可演，不写心理解释，不每句添加，不重复同一神情。
- 心理活动写成：`人物名OS：心理活动`。
- 普通动作不添加人物冒号。
